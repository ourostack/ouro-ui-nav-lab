# Ouro UI nav lab

Five header mockups for [ui.ouroboros.bot](https://ui.ouroboros.bot/), to try on a laptop and a phone: https://ourostack.github.io/ouro-ui-nav-lab/

This is not the site. The source is `site/nav-lab/` on ourostack/ouro-ui's `arimendelow-nav-redesign-mockups` branch; the Preview workflow builds it from there. Once a design is picked and ships in ourostack/ouro-ui, this repository is archived.
